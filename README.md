# Jacqueline Canal Week

A personal trip planner for a narrowboat holiday from Clifton Cruisers, near Rugby, 27 October to 2 November 2026.

Open it at https://gedoalper.github.io/jacqueline-trip/ and, on an iPhone, use Share, then Add to Home Screen. It works offline after the first visit.

## Data and credits

- Map tiles: MapTiler (https://www.maptiler.com/copyright/) and OpenStreetMap contributors.
- Built-in base map, shops and places: OpenStreetMap contributors, ODbL (https://www.openstreetmap.org/copyright). Downloaded 26 Oct 2026.
- Canal places, distances and locks: Canalplan (https://canalplan.uk), read 26 Oct 2026.
- Lock hours and closures: Canal & River Trust notices via Canalplan, read 26 Oct 2026. Check https://canalrivertrust.org.uk/notices before travelling.
- Map library: Leaflet (https://leafletjs.com).

Opening hours and lock rules change. This is a planning aid, not a navigation authority.
